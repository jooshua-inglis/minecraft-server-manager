# M6 — Logs

[← Plan overview](README.md) · Previous: [M5 — Player management](m05-player-management.md) · Next: [M7 — Resource monitoring](m07-resource-monitoring.md)

## Build

`mcm logs <name>` and `mcm logs <name> -f` streaming the container's
stdout/stderr via the Docker SDK.

## Try it

`mcm logs myworld -f` in one terminal while playing/connecting in-game in
another, and watch join/leave/chat lines appear live.
